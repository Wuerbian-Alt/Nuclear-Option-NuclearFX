# Nuclear FX

Nuclear explosion visual feedback mod for Nuclear Option: blinding blackout → gradual brightening → noise → HUD shutdown and reboot → shake

## Installation
1. Install BepInEx 5.4.x (x64)
2. Download NuclearFX-Package.zip from Releases
3. Extract and drag the plugins folder into the game root directory
